Meet Veil.

Veil is a standalone desktop browser written in Java using JavaFX WebView. This page is only the project information page — it is not the browser app.

Run it on your computer

Install JDK 21 and Maven, clone this repository, then run:

mvn clean javafx:run

Type a website address or a search query in the address bar. Queries use DuckDuckGo.

Note: this is an early Java desktop build. It does not yet include comprehensive tracker blocking or anti-fingerprinting protection. See the GitHub repository and README for setup and current limitations.
